# Отчёт исследования

## RUBEZH STRAZH

Карточка сотрудника — responsive SPA с custom element `employee-view`. Поля читаются адаптером по связанным label, затем по `name`, `id`, `placeholder` и `aria-label`. Shadow DOM также обходится. Кнопка привязывается к области штатных действий и восстанавливается через `MutationObserver` без дубликатов.

## CSD

Все три файла начинаются с `43 53 44 00` (`CSD`) и содержат имя очереди `IDP SMART-51 Card Printer`. Это бинарные проекты SMART IDesigner. Внутри находятся объекты `CWObj`, Arial-тексты и PNG/JPEG-ресурсы.

Найденные значения:

| Шаблон | Динамические данные |
|---|---|
| Сотрудник | фамилия, имя, отчество, должность, табельный номер |
| МОСН | фамилия, имя, отчество, должность, маркер МОСН |
| Временный | номер пропуска; статические «ВРЕМЕННЫЙ», «ПРОПУСК» и организация |

Публично документированного API изменения полей CSD в исходных материалах нет. Установленный SMART IDesigner и `SmartComm2.dll` проверяются мостом на Windows. До подтверждения совместимого SDK применяется единый локальный raster pipeline 1012×638 px (CR80, 300 DPI). Исходные CSD не изменяются.

## Ограничения

Реальную версию драйвера, очередь, ленту, printable area и физическую калибровку можно определить только на рабочей Windows-машине. Команда `diagnose` возвращает очереди и найденные SmartComm2 DLL. Перед эксплуатацией обязательна тестовая карта и сверка размера 100%.
