# RUBEZH STRAZH — печать пропусков из браузера

Расширение добавляет непосредственно в карточку сотрудника RUBEZH STRAZH три кнопки рядом с кнопкой сохранения:

- `Печать: сотрудник`
- `Печать: МОСН`
- `Печать: временный`

Нажатие считывает уже введённые ФИО, должность, подразделение, табельный номер и фотографию, формирует карту CR80 размером 85,6 × 54 мм и вызывает стандартное окно печати браузера через `window.print()` — как при `Ctrl+P`.

Отдельная программа и Print Bridge не требуются. Персональные данные никуда не отправляются.

## Установка

1. Скачайте `rubezh-strazh-extension-unpacked-vX.Y.Z.zip` из Releases.
2. Полностью распакуйте архив.
3. Откройте `browser://extensions` в Яндекс Браузере.
4. Включите режим разработчика.
5. Нажмите **«Загрузить распакованное расширение»**.
6. Выберите папку `rubezh-strazh-extension-unpacked`.
7. Откройте настройки расширения, укажите адрес RUBEZH и обновите карточку сотрудника.

В системном окне печати выберите карточный принтер, физический размер CR80/85,6 × 54 мм, масштаб 100% и отключите поля/колонтитулы, если драйвер не применил эти параметры автоматически.
